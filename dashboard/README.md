# Dashboard starter

This is a lightweight static dashboard starter that runs with no build step.

## Run

From repo root:

- `python3 -m http.server 4173`
- Open `http://localhost:4173/dashboard/`

## Features

- Sidebar with section switcher (`Overview`, `Performance`, `Customers`)
- KPI cards that recalculate per selected view + date range
- Canvas trend chart (sessions)
- Activity table with recent rows and key metrics
- Responsive layout for desktop and mobile widths
