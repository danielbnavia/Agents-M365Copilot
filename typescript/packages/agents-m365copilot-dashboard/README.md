# Copilot Dashboard Starter

A lightweight React + Vite dashboard starter for visualizing Microsoft 365 Copilot operations.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## What it includes

- Executive hero summary for rollout state
- KPI cards for adoption, answer quality, escalations, and latency
- Live operations feed and rollout checklist
- Connector health table and org adoption breakdown
